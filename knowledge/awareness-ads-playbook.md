## 1. 認知広告の2つの目的

1. **「何かが始まる」と知ってもらう**（想起形成）。コンバージョン広告が「はじめまして」に
   ならないための下地作り。映画の予告編と同じ発想。
2. **類似オーディエンスの元データを貯める**。動画視聴者（＝商品に興味があり動画を最後まで
   見る人）のカスタムオーディエンスを作るための母集団収集。

補足:
- 無形商材では認知広告のリンク先をLPにしても登録はほぼ発生しない（それでよい。目的はデータと認知）。
  リンク先はLPでもInstagramプロフィールでも可。LPに飛ばす場合はピクセルでデータは貯まる。
- 店舗ビジネスは認知広告だけで来店が発生する（設定を間違えなければ）。

## 2. キャンペーン設定ルール

### 最適化目標（認知度キャンペーンの5種のうち）

| 最適化目標 | 判定 |
|---|---|
| 広告リーチの最大化 | **絶対に使わない**（デフォルトで選択されているので特に注意） |
| インプレッション数の最大化 | 使わない |
| **広告想起リフトの最大化** | ◯ 使う（広告閲覧から2日以内に思い出す可能性が高い人へ配信） |
| **ThruPlay再生数の最大化** | ◯ 使う（動画を15秒以上見る可能性が高い人へ配信）。最近の主力 |

- **想起リフトとThruPlayは両方並行で出し、数値が良い方を残す**。
  「良い」の定義 = 動画100%完全視聴率が高い方（下記KPI参照）。

### ThruPlay成果課金（裏技）

- 最適化目標にThruPlayを選んだ時だけ「その他のオプション」内に課金対象の選択が出現する
  （普段は折りたたまれていて気づけない）。
- **ThruPlay課金**にすると15秒以上視聴された時のみ課金。検証では同一クリエイティブ・同一配信先で
  完全視聴率がインプレッション課金の約2倍、50%視聴率も約4pt高い。
- ただしアカウントの利用実績（信頼残高）が貯まるまで選択不可。解禁の通知は来ないので定期チェック。

### 予算・出稿タイミング

- 認知広告は小予算でよい: **日1,000円程度から**。CPMが極めて安い
  （実績例: 67円/1,000imp。認知CPM 418円 vs コンバージョン広告CPM 2,215円で5倍差）。
- 出稿は**開始の最低2週間前から**。1〜3ヶ月前から出せるならその方がよい（早いほどよい）。
- キャンペーン/オープン開始後も止めない。「開催中」「営業中」訴求に切り替えて出し続ける。
- 季節キャンペーン（例: オータムフェア）も2週間〜1ヶ月前から予告を流し続けると開始時に集中する。

## 3. KPI・判定基準

- カスタム指標として動画再生率 25% / 50% / 75% / 95% / 100%（各再生数 ÷ 動画の再生数、
  フォーマット%）をすべて作成して監視する。
- **合格ライン: 動画100%完全視聴率 ≥ 2%**（100人が見たら2人が最後まで見る）。
  2%を下回るクリエイティブは改善対象。
- 認知広告のフリークエンシーは高くてよい（2超え歓迎。10でも20でも問題ない）。
  ※コンバージョン広告は目安2前後、超えると飽きられる。
- CTRの参考合格ライン: 無形商材 1% / 店舗 2%。
- CPMは「安いほど良い」ではない。高CPM=Metaにとって良い広告主=質の高い配信先の可能性。
  最終評価は来店・セミナー参加など顧客の質で行う。
- CPMの決定要因: 入札、広告へのエンゲージメント、広告品質（報告・非表示率）、
  遷移先LPの滞在時間（短時間離脱の繰り返しはCPM悪化。CVすれば滞在が短くてもOK）。
- ROAS合格ライン: 300%（広告費の3倍の売上。これ未満は諸経費込みで利益が残らない）。

## 4. クリエイティブテストの回し方

- **冒頭（フック）で視聴率が決まる**。冒頭違いを3パターン程度作り、日1,000円×2〜3日でテスト
  → 完全視聴率が最も高いものに予算を一気に寄せる。
- ターゲティングはブロード配信 / 詳細ターゲット / 類似配信をすべて試す。
  評価基準は常に「完全視聴率2%超えか」。
- 想起リフト用とThruPlay用は**同一クリエイティブでもファイル名を変えて別アップロード**する
  （上級テク）。目的: 最適化目標別に視聴者オーディエンスを分離し、後段のコンバージョン広告で
  「どちら由来の類似オーディエンスのCPAが安いか」を検証可能にするため。

### クリエイティブ構成テンプレート

**無形商材（講座・セミナー）向け:**
インパクトのあるメッセージ → 本編動画（アイキャッチ）→ お客様の声×2 → ノウハウ →
アイキャッチ → 本編 → オファー。ストーリー調が最強。

- メインテキストに「動画を最後まで見ると（特典）がもらえます」の要素を入れて視聴維持率を上げる。
- 見出しは「無料」だけでは弱い。「いつまで無料」と期限を付ける。
- ストーリー調テキストの型: ①臨場感の伝わる描写 → ②ノウハウ → ③成果が出た理由 →
  ④ビフォー→アフターの結果（エビデンスベース）→ ⑤感情のメッセージ → ⑥理想の未来
  （冒頭で開いた風呂敷を必ず閉じる）→ オファー。
- 訴求ワードで集まる客の質が決まる。「簡単・手軽」訴求は質の低い客（行動しない・支払い能力が低い）
  を集める。実績・向上心訴求は質の高い客を集める。同一商品でも売上が1,000万円以上変わった実例あり。

**店舗向け:**
既視感 + 疑似体験。地元の誰もが知る駅・商業施設から店舗までの道順を見せ（「あれ、私の最寄駅だ」）、
施術風景で来店前から疑似体験させ、最後にオファー。割引訴求は不要（「お得な入会キャンペーン」程度でよい）。
実績例: LINE登録単価100円台・20万円で300登録→95予約→65契約、来店数1.8倍。

## 5. 類似オーディエンス構築（ROAS 1000%超の3ステップ）

1. **認知広告**（上記テンプレート）で動画を配信する。
2. **動画視聴者のカスタムオーディエンスを作成**して類似化する。
   - 最初のゴール: 視聴者リストの分母1,000件。
   - 100%視聴で1,000件貯めるのが理想だが時間がかかるため、まず**50%視聴**で作るのが現実的
     （予算が潤沢なら100%で一気に）。
   - オーディエンス作成: カスタムオーディエンス → 動画 → 「50%まで再生した人」→
     リテンション最大365日 → 対象動画を選択。
   - そこから**類似オーディエンス1% / 3% / 5%**を作成。
3. **コンバージョン広告を類似オーディエンスに当てる**。
   - 実績: ROAS 1,000〜2,800%の事例多数。600%事例 = 認知動画50%視聴者の類似5%へ
     Advantage+配置・25歳以上で配信、100万円→売上660万円。

- この3ステップは無形商材・有形商材・店舗すべて共通で実施する。
- 認知広告用の動画とコンバージョン広告用の動画は別物として作る
  （認知用動画をCV広告に流用するとリードは取れても質が合わない事故が起きる）。

## 6. コンバージョン広告側の運用原則（連携時の参考）

- **ASC（Advantage+ Sales Campaign）とA+A（Advantage+ オーディエンス配信）は必ず両方配信**。
  A+AはASCの配信データの一部を使う（Meta公式）ため、ASCありきで相乗効果が出る。
- 構成は1キャンペーン=1広告セット=1広告。ASC用とA+A用で別キャンペーンを立て、
  予算比率（5:5 / 4:6 / 3:7…）を変えながら**広告アカウント全体のCPA**が最安になる
  ゴールデンルールを案件ごとに探す。キャンペーン単体の数値で切らない。
- 小予算でも比率分割から始める（どちらかに寄せない）。
- ASCの推奨予算はMeta公称で月3万円程度〜だが必須ではない。
- Advantage+のバリュー機能: 特定年齢・性別への配信量を -90%〜+1000% で調整可能。
  増やす設定と減らす設定のどちらが安いかはテストで確認。
- 除外設定: 既存顧客（メルマガリスト等のカスタムオーディエンス）を「既存顧客」に設定し、
  予算上限0%にして初めて配信除外になる。
- ピクセル標準イベント: 登録完了ページに CompleteRegistration、購入完了に Purchase を必ず設置
  （ゴール指定タグ。無いと計測不能）。Purchase使用時は通貨をUSD→JPYに変更。
  ポータルサイト（ホットペッパー等）に飛ばすと計測できない。

## 7. AdDroid適用時の要点（本プレイブックの運用への翻訳）

- 認知キャンペーンの optimization_goal は AD_RECALL_LIFT または THRUPLAY のみ許可。
  REACH / IMPRESSIONS は警告対象。
- 認知クリエイティブの勝敗判定は「完全視聴率 = video_p100_watched ÷ 動画再生数（≥2%が合格）」
  と「完全視聴単価 = spend ÷ video_p100_watched」で行う。CPA・CVは認知段階では使わない。
- 認知のフリークエンシー超過アラートは不要（高頻度OK）。コンバージョン広告のみ frequency>2 を監視。
- テストは小予算（日1,000円/本）短期（2〜3日）→勝者に予算集中、のループ。
- 動画視聴者1,000件到達を類似オーディエンス作成の提案トリガーにする。
